# FLOW FIT

FLOW FIT es una aplicación web desarrollada en JavaScript para gestionar productos de indumentaria deportiva.

El proyecto permite visualizar, buscar, agregar, editar y eliminar productos. Los productos se almacenan en `localStorage` para conservar los cambios realizados por el usuario.

También se utiliza un archivo `data.json` para cargar los productos de forma asíncrona mediante `fetch()`.

## Funcionalidades principales

- Visualización dinámica de productos.
- Búsqueda de productos por nombre.
- Agregar nuevos productos.
- Editar productos existentes.
- Eliminar productos.
- Vaciar la lista de productos.
- Persistencia de datos mediante `localStorage`.
- Carga de datos desde `data.json` mediante `fetch()`.
- Manejo de operaciones asincrónicas con `async/await`.
- Manejo de errores con `try/catch`.

## Cómo ejecutar el proyecto localmente

1. Descargar o clonar este repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Iniciar un servidor local utilizando la extensión **Live Server**.
4. Hacer clic derecho sobre `index.html` y seleccionar **Open with Live Server**.
5. La aplicación se abrirá en el navegador.
